# Security Policy

## Overview

This document outlines security expectations and reporting guidance for Hot and Bothered SensorHub.

The project includes hardware and software elements such as:

- ESP32-based firmware
- DS18B20 sensor inputs
- optional relay handling
- web interface access
- MQTT communication
- local and remote monitoring use cases

Because the project may be used in technical installations and service-monitoring workflows, basic operational security matters even if the system is not positioned as an enterprise product.
