# User Guide

## Overview

Hot and Bothered SensorHub is an ESP32-based temperature monitoring and relay-control hub for heating, hot-water, and technical installation monitoring.

It is designed to collect sensor values, publish them to MQTT, expose a local web interface, and support practical integrations such as Home Assistant, ThingsBoard, and the related display project.

This guide focuses on practical setup and day-to-day use.

## Typical use cases

The SensorHub is useful for:

- monitoring boiler, buffer, and line temperatures
- checking whether hot water is available before the day starts badly
- publishing installation data to MQTT
- driving a local display client
- giving installers or service partners a quicker view of system state
